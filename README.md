# 🔊 Sound Stream

**Слушай звук с компьютера на телефоне — прямо в браузере, без приложений.**

Сервер захватывает системный звук ПК (всё, что играет из колонок) и транслирует
его на телефон по локальной сети. Открыл ссылку — и слушаешь.

## 💡 Кому пригодится

- 🎧 **Беспроводные наушники не подключаются к ПК** — подключи их к телефону, а звук компьютера направь на телефон
- 🔈 **Нужна быстрая колонка для ПК или ноутбука** — превращает телефон в внешний динамик за секунды
- 🛋️ **Хочешь отойти от компьютера** — слушай то, что играет на ПК, не вставая

## ✨ Возможности

- 🎧 **Системный звук целиком** — захват всего, что играет из колонок ПК
- 📱 **iPhone и Android** — работает в любом телефоне, ставить приложение не нужно
- ⚡ **Захват по требованию** — поднимается, когда подключается первый слушатель, и гаснет, когда все ушли
- 🌙 **Аккуратный плеер** — glass-интерфейс, тёмная тема, регулировка громкости
- 🪶 **Без зависимостей-тяжеловесов** — Express + WebSocket, моно Int16 PCM

## 📦 Требования

- **Windows** (захват построен на WASAPI loopback)
- **Node.js 18+**
- ПК и телефон в **одной Wi-Fi сети**

## 🚀 Запуск

```bash
npm install
npm start
```

В консоли появится адрес — открой его на телефоне:

```
sound-stream running
Источник: системный звук ПК (WASAPI loopback) —   включится при подключении слушателя

Открой на телефоне (та же WiFi):
http://YOUR_IP:47823/
```

Порт можно поменять переменной окружения `PORT` (по умолчанию `47823`).

## ⚙️ Как это устроено

```
  ПК (колонки)
      │  WASAPI loopback (audify / RtAudio)
      ▼
  capture.js ──► даунмикс в моно Int16 PCM, кадры ~10 мс
      │
      ▼
  server.js ──► Express + WebSocket
      │  бинарные PCM-кадры
      ▼
  📱 listen.html ──► воспроизведение в браузере телефона
```

Захват открывается **по требованию**: при первом подключившемся слушателе сервер
поднимает loopback, рассылает формат и звук, а когда слушателей не остаётся —
останавливает захват.

## 📁 Структура

| Файл | Назначение |
|------|------------|
| `server.js` | HTTP + WebSocket сервер, раздача страницы и звука |
| `capture.js` | Захват системного звука через WASAPI loopback |
| `public/listen.html` | Страница-плеер для телефона |
